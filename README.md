# Aeshbuy

Aeshbuy is a Nigerian commerce, cashback, loyalty, and merchant-services platform built around **Buy → Earn → Redeem → Buy Again**.

The backend is a production-oriented NestJS modular monolith using PostgreSQL, Prisma, Redis, BullMQ, and Paystack. Foundation implementation is complete; identity and business-domain modules are still pending. See the progress tracker for the evidence-backed status.
